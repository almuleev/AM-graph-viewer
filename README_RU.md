# AM Graph Viewer

<p align="center">
  <img src="docs/assets/github-banner.png" alt="Баннер AM Graph Viewer">
</p>

Нативный Win32-просмотрщик и CLI-инструмент для работы с файлами сигналов LabVIEW `.lvm` / `.txt`.

## Зачем нужен проект

`AM Graph Viewer` сделан для быстрой инженерной работы с логами LabVIEW без тяжёлых внешних зависимостей:

- без Qt
- без отдельного GUI-runtime
- без сложной установки
- с быстрым открытием реальных измерительных файлов
- с удобным интерактивным просмотром и CLI-режимом

## Основные возможности

### Desktop-приложение

- просмотр сигнала во времени и в режиме FFT
- масштабирование, панорамирование, playback и auto zoom
- светлая и тёмная тема
- русский и английский интерфейс
- переименование каналов прямо в списке
- экспорт PNG, CSV и TXT
- drag & drop открытия файла

### Измерения и анализ

- примагничиваемые точки измерения
- независимые группы точек со своим цветом и видимостью
- отображение `X`, `Y`, `Δx`, `Δy`, `1/Δt` и расстояния
- вертикальные и горизонтальные направляющие
- маркеры
- undo/redo для точек, линий и маркеров

FFT принимает неравномерные и округлённые метки времени: перед расчётом значения
линейно интерполируются на равномерную сетку той же длины и длительности без больших разрывов.
Разрыв больше 1,5 оценённого шага времени сжимается до одного шага на шкале FFT,
но не исключает данные: в расчёт попадают все отсчёты выбранного диапазона по обе
стороны любого числа пропусков. Это отмечается в статусе и метаданных экспорта
спектра. Интерполяция
может сглаживать высокие частоты; для точного анализа предпочтительна исходная
равномерная запись. Исходные данные во временном режиме остаются прежними.

Шаг определяется по медиане интервалов. Если короткие интервалы отделены от
длинных разрывов более чем в четыре раза, используется медиана короткой группы
(минимум два интервала), даже когда разрывов больше обычных интервалов.
Для преобладающих коротких пропусков также проверяется, что интервалы кратны
медиане короткой группы с отклонением не более 5% одного шага.
Это оценка: по одной временной оси нельзя однозначно отличить смену частоты
записи от пропусков. Если все интервалы одинаково длинные, для восстановления
исходной частоты нужна дополнительная информация о шаге дискретизации.
Пустые значения каналов (`NaN`) обрабатываются отдельно: заменяются средним
значением канала, а не удаляются со сдвигом данных других каналов.

### CLI-режим

- структура файла и информация парсера
- статистика по каналам
- экспорт в CSV
- просмотр FFT-пиков
- обработка выбранного временного окна

### Исправления в текущей разработке

- Light Mode учитывает все отсчёты при вычислении минимума и максимума; одиночные выбросы не теряются.
- В Light Mode FFT рассчитывается в фоне для запрошенных каналов. Скрытие и повторный показ канала из текущего кэша не запускают FFT заново. Для канала вне кэша создаётся новое задание по видимым каналам; кэш содержит результат последнего задания, а не все когда-либо просмотренные каналы. Изменение участка или обработки требует пересчёта.
- В настройках есть «Склеивать пропуски времени на графике». Этот режим сжимает только экранную временную ось и навигацию; исходные данные, измерения и экспорт сохраняют фактическое время.
- Ползунок фильтра применяет значение после отпускания. Одно движение отменяется одним Undo вместе с изменениями измерений.
- История хранит не более 128 действий и 64 МиБ полезной нагрузки. При достижении лимита удаляются старые действия; действие, превышающее весь лимит, очищает историю.
- CSV/TXT со столбцом `Frequency` открывается как готовый спектр. Для него доступны частотный просмотр и экспорт; временной сигнал из такого файла не восстанавливается.
- Windows CLI принимает Unicode-пути. `build_cli.ps1` и `build_gui.ps1` используют версию текущего checkout с отметкой `dirty` при изменениях. `Start GUI.bat` выбирает самый свежий exe.
- Регрессионные проверки: `make test` и, на Windows, `make test-gui`. Workflow CI собирает CLI/ядро на Linux и GUI/CLI на Windows.

## Быстрый старт

### Готовая сборка

Откройте [последний релиз](https://github.com/almuleev/am-graph-viewer/releases/latest) и скачайте Windows `.exe`.

### Сборка GUI

```powershell
powershell -ExecutionPolicy Bypass -File .\build_gui.ps1
```

### Сборка CLI

```bash
make
```

### Запуск тестов

```bash
make test
```

## Техническая основа

- Язык: `C++17`
- GUI-стек: `Win32 API + GDI/GDI+`
- Рекомендуемый toolchain под Windows: `MSYS2 / MinGW g++`
- Имя GUI-бинарника берётся из текущего git-тега и собирается как `AMGraphViewer-v0.12.0-win-x64.exe`
