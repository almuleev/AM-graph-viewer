# Статус исправлений после аудита

Изменения находятся в рабочем дереве. Коммит и публикация релиза не выполнялись.
Исходный аудит: [REVIEW_2026-09-05_RU.md](REVIEW_2026-09-05_RU.md). Это отчёт о прежнем состоянии, а не список открытых дефектов текущего кода.

## Исправлено и проверено

- Экспорт: защита существующего файла при ошибке, однократное применение обработки, соответствие каналов и их метаданных, структура LVM, CSV с кавычками и многострочными названиями, безопасные заголовки TXT.
- Парсер: пустое время не сдвигает столбцы; полная и оконная загрузка используют одинаковую нормализацию; GUI использует индекс сканирования с проверкой размера и времени изменения файла.
- FFT: ограничение выборки не прореживает сигнал; неравномерные метки интерполируются, большие разрывы сжимаются на шкале FFT без исключения отсчётов. Фоновый worker отменяет устаревшие задания. Исправлен масштаб после повторного переключения режима.
- Готовый спектр: Frequency/plot_mode распознаются при чтении. Частоты и амплитуды открываются без FFT, временных формул и удаления совпадающего с осью амплитудного канала. Сведения об исходном участке и интерполяции сохраняются при повторном экспорте.
- Формулы и фильтры: некорректные выражения отвергаются, ошибки области определения не подменяются исходным сигналом, все каскады фильтра сбрасываются при разрывах. Фильтр вынесен в отдельный модуль.
- Отрисовка: точные минимумы/максимумы используются и в графике, и в автомасштабе Light Mode; плотный спектр не пропускает частотные бины; диапазоны больше не сужаются до float.
- Пропуски: добавлен режим экранного склеивания временной оси. Он работает с любым числом разрывов, в том числе тысячами, и не изменяет исходную временную шкалу в Dataset или экспорте.
- Undo: одно движение ползунка — одно действие после отпускания; восстановление настроек восстанавливает удалённые измерения. История ограничена 128 действиями и 64 МиБ полезной нагрузки.
- Память: удаление дублирующих столбцов перемещает данные; фильтрация использует исходные данные/имеющийся кэш без лишней копии; выключение фильтра и упрощение формулы освобождают ненужные кэши.
- Загрузка: потоки завершаются через join, исключения перехватываются; отмена проверяется также на стадиях подготовки и при применении результата.
- Сборка: исправлены зависимости Makefile; версии GUI/CLI и упаковки используют git describe с hash/dirty; добавлен build_cli.ps1; запуск выбирает самый свежий exe. Упаковка не удаляет существующий каталог назначения.
- Читаемость: файловые операции, фильтры и FFT-worker вынесены в модули; определение записи метаданных больше не разрезано между двумя файлами.

## Остаётся

1. Подготовка снимка данных, вычисление формул/фильтров и первичное построение min/max всё ещё могут занимать UI-поток. Нужны фоновые задания для всего конвейера и измерение задержек/пиковой памяти на больших реальных файлах.
2. Настройки: запись отложена таймером, но INI всё ещё хранится рядом с exe и обновляется серией Win32-вызовов. Нужны каталог пользователя для установки без прав записи, миграция и атомарное сохранение с диагностикой ошибок.
3. GUI остаётся преимущественно одной единицей трансляции с глобальным App. Полное разделение Document/Viewport/Controllers и RAII для Win32-ресурсов не завершено.
4. DPI 100/150/200%, клавиатурная навигация, отказ создания GDI-ресурсов и длительная ручная работа в GUI ещё не проверены.
5. Для обычных временных файлов дублирующие X-столбцы пока определяются также по значениям. Нужна опора на структуру LVM, чтобы гарантированно сохранять измерительный канал, случайно совпавший со временем.
6. Нужны единый каталог переводов, более подробная статистика исправленных/пропущенных данных, проверка ресурсов версии exe и удалённого CI.
7. Предложения о новых возможностях (файл проекта, дополнительные виды анализа и т. п.) из исходного аудита в этот этап не включались.
